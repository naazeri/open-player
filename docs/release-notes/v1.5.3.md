### Fixes
- **No more hangs while macOS asks for folder access.** Opening a file in a protected folder
  (for example Downloads or an external drive) can wait for a macOS permission dialog, which may
  appear on another display. Quitting the app in that state froze it; now it quits right away, and
  after a few seconds the window explains what it is waiting for, with a button to Privacy settings.
- **Permissions stay after updates.** The app is now signed with a fixed certificate, so macOS keeps
  the folder permissions you grant. After this update it may ask once more; from then on it won't.
