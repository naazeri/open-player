### What's new
- **Automatic updates.** Open Player now installs new versions itself: when an update is out, it
  shows what changed and installs it with one click (**Install Update**), then restarts. Updates are
  signed, and the app checks the signature before installing. No more downloading, replacing the
  app, or clicking "Open Anyway" again.
- **DMG download.** Besides the zip, each release now has a disk image: open it and drag
  Open Player onto Applications.

Coming from 1.3.x? Install this version by hand one last time; after that, updates install themselves.
